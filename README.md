# MAXIMOFF Support Demo

A standalone, browser-based prototype of a wellbeing support page. It uses simple keyword cues and local-only demo interactions; it is not a mental-health assessment and does not send alerts or contact counsellors.

## Run

Open `index.html` in a modern browser. Bootstrap styling and fonts load from CDNs, so an internet connection is needed for those assets. Voice recognition is browser-dependent and may use the browser provider's speech service. Microphone and camera features may require serving the page from `localhost` or HTTPS.
